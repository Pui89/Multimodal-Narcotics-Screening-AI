# PUI89 Sentinel — กรอบบัญชีน้ำหนักและการคำนวณขนาดชุดขับ v0.1

**สถานะ:** กรอบการคำนวณเบื้องต้น; ยังไม่มีการเลือกฮาร์ดแวร์  
**วันที่:** 2026-11-21  
**ขอบเขต:** หุ่นยนต์สี่ขาภายใต้การกำกับของมนุษย์  
**เป้าหมายน้ำหนักเบื้องต้น:** 18–22 กก. สำหรับหุ่นยนต์ทั้งระบบ  
**การจัดซื้อ / ผลิต / นำไปใช้งาน:** ไม่ได้รับอนุญาตจากเอกสารนี้

## 1. วัตถุประสงค์และขอบเขตการตัดสินใจ

เอกสารนี้กำหนดวิธีเปลี่ยนภารกิจตรวจสอบของ Sentinel ที่ได้รับการเลือกแล้ว ให้เป็นบัญชีน้ำหนักรายระบบ แบบจำลองแรงที่ข้อต่อ ข้อกำหนดชุดขับ ค่าประมาณกำลังไฟฟ้า และพลังงานแบตเตอรี่ที่ตรวจสอบย้อนกลับได้

เอกสารนี้ **ยังไม่เลือก** มอเตอร์ เกียร์ แบตเตอรี่ เซนเซอร์ ผู้ขาย หรือวัสดุ และไม่ได้ยืนยันว่าหุ่นยนต์ทำได้ตามเป้าหมาย 18–22 กก. ไม่ควรตรึงค่าการคำนวณเชิงตัวเลขจนกว่าจะกำหนดภารกิจ รูปทรง กลไกการเดิน น้ำหนักบรรทุก ขอบเขตการใช้งาน และปัจจัยความปลอดภัย

Sentinel ยังคงเป็นหุ่นยนต์สี่ขา แตกต่างจาก PUI89 AI NOMAD ซึ่งเป็นหุ่นยนต์สี่ล้อ

## 3. บัญชีน้ำหนักหุ่นยนต์ทั้งระบบ

เป้าหมายเบื้องต้นที่ได้รับอนุมัติคือ **18–22 กก. สำหรับหุ่นยนต์พื้นฐานทั้งระบบ** โดยต้องนับรายการต่อไปนี้:

| ระบบย่อย | รายการที่รวม | น้ำหนักแผน (กก.) | หลักฐาน / ผู้รับผิดชอบ |
|---|---|---:|---|
| ลำตัวและโครงสร้างหลัก | แชสซี ขายึด ฝาครอบรับแรง และตัวยึด | ยังไม่กำหนด | CAD + ข้อมูลวัสดุ/ชิ้นส่วน |
| โครงสร้างขาทั้งสี่ | ลิงก์ ตัวเรือนข้อต่อ แบริ่ง เพลา และตัวยึด | ยังไม่กำหนด | CAD + ข้อมูลชิ้นส่วน |
| ชุดขับและระบบส่งกำลัง | มอเตอร์ เกียร์ สายพาน/เฟือง เบรกเมื่อจำเป็น และฐานยึด | ยังไม่กำหนด | Datasheet รุ่นจริง + แบบออกแบบ |
| เท้าและส่วนสัมผัสพื้น | โครงสร้างเท้า ส่วนยืดหยุ่น และแผ่นสัมผัสที่เปลี่ยนได้ | ยังไม่กำหนด | CAD + ผลทดสอบ |
| แบตเตอรี่และ BMS | เซลล์ กล่อง BMS ระบบป้องกัน และฐานยึด | ยังไม่กำหนด | Datasheet เซลล์/BMS |
| อิเล็กทรอนิกส์กำลัง | ไดรเวอร์ DC/DC ระบบจ่ายไฟ ฟิวส์ และชุดสายไฟ | ยังไม่กำหนด | Datasheet + แบบวงจร |
| คอมพิวเตอร์และหน่วยเก็บข้อมูล | คอมพิวเตอร์บนตัวหุ่นยนต์ หน่วยเก็บข้อมูล ระบบระบายความร้อนและฐานยึด | ยังไม่กำหนด | Datasheet รุ่นจริง |
| เซนเซอร์พื้นฐาน | IMU การวัดสถานะข้อต่อ/เท้า กล้อง และเซนเซอร์ที่ไม่ขึ้นกับภารกิจเฉพาะ | ยังไม่กำหนด | Datasheet รุ่นจริง |
| Payload ตามภารกิจ | เซนเซอร์ ไฟส่องสว่าง หรือเครื่องมือเฉพาะภารกิจ | แยกไว้ก่อน | ต้องได้รับอนุมัติภารกิจ |
| ฝาครอบและการป้องกันสภาพแวดล้อม | ฝาครอบ ซีล การ์ด และช่องซ่อมบำรุง | ยังไม่กำหนด | CAD + ทดสอบสภาพแวดล้อม |
| สายไฟและขั้วต่อ | ชุดสายภายใน ขั้วต่อ และอุปกรณ์ป้องกันแรงดึง | ยังไม่กำหนด | ประมาณการชุดสาย |
| **น้ำหนักรวมพื้นฐาน** | รวมทุกรายการพื้นฐาน พร้อมระบุการนับ payload ให้ชัดเจน | **เป้าหมาย 18–22** | ตรวจทานบัญชีน้ำหนักรวม |

หลักการ:
- ห้ามนับน้ำหนักซ้ำ หากรวมอยู่ในน้ำหนักชุดประกอบจากผู้ผลิตแล้ว
- แยกน้ำหนักที่ประมาณจากแบบ น้ำหนักตาม datasheet น้ำหนักจาก CAD และน้ำหนักที่ชั่งจริง
- เพิ่มค่าน้ำหนักเผื่อเมื่อประเมินความไม่แน่นอนแล้วเท่านั้น และแสดงเป็นรายการแยก ไม่ซ่อนในค่าน้ำหนักชิ้นส่วน
- แยก payload จนกว่าจะอนุมัติให้รวมใน configuration อย่างเป็นทางการ
- ตรวจสอบยอดรวมเทียบเป้าหมาย 18–22 กก. ทุกครั้งที่ทบทวนแบบ หากทำไม่ได้ต้องบันทึก trade-off และขออนุมัติเปลี่ยนเป้าหมาย ห้ามลดระยะเผื่อความปลอดภัยโดยไม่เปิดเผย

## 4. วิธีคำนวณแรงและแรงบิดที่ข้อต่อ

### 4.1 กำหนดกรณีรับแรง

อย่างน้อยต้องจำลอง:
1. ยืนอยู่กับที่บนพื้นระดับ
2. เดินช้าแบบควบคุม รวมช่วงที่มีหนึ่งขา สองขา หรือหลายขารับน้ำหนักตาม gait ที่เลือก
3. เร่ง ลดความเร็ว และเลี้ยว
4. เดินขึ้น/ลงทางลาด และทางลาดด้านข้าง
5. ก้าวขึ้น/ลงขั้น และข้ามสิ่งกีดขวาง
6. แรงกระแทกจากเท้า การแก้การลื่น และการหยุดอย่างควบคุม
7. น้ำหนักบรรทุกสูงสุด/ต่ำสุดและการเยื้องของจุดศูนย์ถ่วง
8. ภาวะขัดข้องหรือระบบเสื่อมสภาพที่ต้องหยุดอย่างปลอดภัย

ทุกกรณีต้องระบุน้ำหนักหุ่นยนต์ payload ท่าทาง จุดสัมผัสเท้า สมมติฐานพื้นผิว ความเร่ง ความไม่แน่นอน และตัวคูณการออกแบบ

### 4.2 การตรวจสอบแรงรองรับขั้นต้น

สำหรับการตรวจสอบสถิตแบบง่ายเท่านั้น:

\[
W = m g, \qquad F_{z,\,foot} \approx \frac{m g}{n_s}
\]

โดย (m) คือน้ำหนักมวลที่รองรับ (g) คือความเร่งโน้มถ่วง และ (n_s) คือจำนวนเท้าที่สมมติให้รับแรง การแบ่งแรงเท่ากันนี้ **ไม่ใช่** ค่าทำนายแรงขาระหว่างการเคลื่อนที่ และห้ามใช้เพียงอย่างเดียวในการเลือกชุดขับ

กรณีไดนามิกต้องแก้สมดุลแรงและโมเมนต์ของลำตัวและขา โดยรวมแรงเฉื่อย เงื่อนไขการสัมผัสพื้น และ gait ที่เลือก ใช้ multibody simulation หรือแบบจำลอง inverse dynamics ที่ผ่านการตรวจสอบ

### 4.3 แรงบิดข้อต่อ

สำหรับ Jacobian ของขา (J(q)) และเวกเตอร์แรงที่เท้า/จุดสัมผัส (F):

\[
\tau_{joint} = J(q)^T F + \tau_{gravity} + \tau_{inertia} + \tau_{friction}
\]

ต้องใช้กรอบพิกัด ทิศทางเครื่องหมาย และหน่วยให้สอดคล้องกัน รวมท่าทางและเรขาคณิตการสัมผัสที่มีภาระสูงสุดที่น่าเชื่อถือ ไม่พิจารณาเฉพาะท่ายืนปกติ ตรวจสอบแบบจำลองด้วยการจำลอง และในระยะต่อไปด้วยการวัดบนแท่นทดสอบ

สำหรับระบบส่งกำลังที่มีอัตราทด (N = \omega_{motor}/\omega_{joint}) และประสิทธิภาพ \(\eta_g\) ค่าประมาณด้านมอเตอร์ขั้นต้นคือ:

\[
\tau_{motor} \approx \frac{\tau_{joint}}{N\eta_g}, \qquad
\omega_{motor} = N\omega_{joint}
\]

ความสัมพันธ์นี้เป็นเพียงค่าประมาณเพื่อกำหนดขนาด ประสิทธิภาพเกียร์เปลี่ยนตามความเร็ว แรงบิด อุณหภูมิ และทิศทาง ต้องพิจารณา backlash ความยืดหยุ่น ภาระสูงสุด ขีดจำกัดแบริ่ง และภาระความร้อนด้วย

### 4.4 ภาระแรงบิดสูงสุด ต่อเนื่อง และ RMS

ห้ามเลือกชุดขับจากแรงบิดสูงสุดเพียงค่าเดียว สำหรับ duty cycle ที่เกิดซ้ำและมีแรงบิด \(\tau_i\) เป็นเวลา \(t_i\) ค่า RMS แบบง่ายคือ:

\[
\tau_{RMS} = \sqrt{\frac{\sum_i \tau_i^2 t_i}{\sum_i t_i}}
\]

เปรียบเทียบแรงบิดสูงสุด แรงบิดต่อเนื่อง/RMS ช่วงความเร็ว-แรงบิด ระยะเวลาที่อนุญาตสำหรับภาระสูงสุด ขีดจำกัดความร้อน และอายุการใช้งานกับ datasheet ของชุดขับและระบบส่งกำลังรุ่นจริง ค่า RMS ไม่สามารถใช้แทนแบบจำลองความร้อนของผู้ผลิตหรือการวิเคราะห์ duty cycle ทั้งภารกิจได้

### 4.5 กำลังกล

\[
P_{mech}(t) = \tau(t)\,\omega(t)
\]

ประเมินช่วงใช้พลังงานและช่วงเบรก/คืนพลังงานแยกกัน กำลังไฟฟ้าขาเข้าต้องรวมการสูญเสียของมอเตอร์ ไดรเวอร์ และระบบส่งกำลัง ห้ามสมมติว่าจะนำพลังงานจากการเบรกกลับมาใช้ได้ หากไดรเวอร์ แบตเตอรี่ และระบบควบคุมยังไม่ได้ออกแบบและตรวจสอบความสามารถดังกล่าว

## 5. แบบฟอร์มข้อกำหนดชุดขับรายข้อต่อ

จัดทำข้อมูลแยกสำหรับแต่ละข้อต่อ ไม่ใช้การเลือกมอเตอร์รุ่นเดียวแทนทุกข้อต่อ

| รายการ | ค่าที่ต้องกำหนด |
|---|---|
| รหัสข้อต่อ / ขา / แกน | ยังไม่กำหนด |
| ช่วงการหมุนและจุดหยุดเชิงกล | ยังไม่กำหนด |
| แรงบิดสูงสุดที่ข้อต่อต้องการ | คำนวณแยกตามแต่ละกรณีรับแรง |
| แรงบิดต่อเนื่อง / RMS | คำนวณจาก duty cycle ของภารกิจ |
| ความเร็วและความเร่งของข้อต่อ | คำนวณจาก gait และรูปทรง |
| กำลังขาออกและการระบายความร้อน | คำนวณและตรวจสอบ |
| อัตราทดและแผนที่ประสิทธิภาพระบบส่งกำลัง | ยังไม่กำหนดจาก datasheet ของรุ่นที่พิจารณา |
| Backlash ความแข็ง และขีดจำกัดแรงแบริ่ง/แรงด้านข้าง | ยังไม่กำหนด |
| การวัดตำแหน่ง/ความเร็ว/แรงบิด | ยังไม่กำหนด |
| แรงดัน/กระแสไดรเวอร์และระยะเวลาภาระสูงสุด | ยังไม่กำหนด |
| พิกัดสภาพแวดล้อมและอายุใช้งาน | ยังไม่กำหนด |
| ผู้ผลิต หมายเลขชิ้นส่วนจริง ประเทศที่ผลิต และหลักฐานแหล่งกำเนิด | ต้องมี ก่อนประเมิน |
| แหล่งที่มาของเฟิร์มแวร์/ซอฟต์แวร์และการควบคุมการอัปเดต | ต้องมี ก่อนบูรณาการ |
| การตรวจสอบเจ้าของ/ผู้ควบคุมผู้ขายและความสามารถในการเปลี่ยนทดแทน | ต้องมีตามนโยบาย PUI89 |

ไม่รับพิจารณาชุดขับที่ไม่สามารถตรวจสอบพิกัดแรงบิดต่อเนื่อง กราฟความเร็ว-แรงบิด เงื่อนไขความร้อน ระยะเวลาภาระสูงสุด ขีดจำกัดเชิงกล หรือแหล่งที่มาได้

## 6. การคำนวณกำลังไฟฟ้าและแบตเตอรี่

จัดทำโปรไฟล์ภารกิจตามเวลา ในแต่ละช่วงให้บันทึกระยะเวลาและกำลังไฟฟ้าของ:
- แอคชูเอเตอร์ข้อต่อและไดรเวอร์มอเตอร์ รวมช่วงพัก/ค้างตำแหน่งและภาระชั่วขณะ
- คอมพิวเตอร์ หน่วยเก็บข้อมูล และระบบระบายความร้อน
- เซนเซอร์ ไฟส่องสว่าง และการสื่อสาร
- การสูญเสียจาก DC/DC และระบบจ่ายไฟ
- พลังงานสำรองสำหรับหยุดอย่างปลอดภัยและกลับสู่จุดเริ่มต้น

พลังงานที่ขั้วแบตเตอรี่ประมาณจากการอินทิเกรตโปรไฟล์โหลด:

\[
E_{load} = \int_0^T P_{battery}(t)\,dt
\]

สำหรับภารกิจที่แบ่งเป็นช่วง:

\[
E_{load} \approx \sum_i P_{battery,i}\,t_i
\]

ข้อกำหนดพลังงานแบตเตอรี่พิกัดเบื้องต้นเขียนได้เป็น:

\[
E_{nominal} \geq \frac{E_{load}}{f_{usable}\,\eta_{system}}
\]

โดย (f_{usable}) คือสัดส่วนพลังงานแบตเตอรี่พิกัดที่อนุญาตให้ใช้ และ \(\eta_{system}\) คือประสิทธิภาพรวมของการแปลง/จ่ายไฟที่ยังไม่ได้รวมใน (P_{battery}) ต้องนิยามตัวแปรให้สอดคล้องกันเพื่อไม่ให้นับการสูญเสียซ้ำ เพิ่มพลังงานสำรองสำหรับการหยุด/กลับอย่างปลอดภัยและผลจากอายุแบตเตอรี่/อุณหภูมิเมื่อทราบภารกิจและข้อจำกัดของเซลล์แล้วเท่านั้น

ต้องตรวจสอบเพิ่มเติม:
- กระแสสูงสุดและต่อเนื่องของบัส แรงดันตก และพิกัดขั้วต่อ
- การป้องกันกระแส อุณหภูมิ แรงดันเซลล์ และลัดวงจรของ BMS
- เคมีของเซลล์ อุณหภูมิใช้งาน ขีดจำกัดการชาร์จ และข้อกำหนดการขนส่ง
- กล่องแบตเตอรี่ การป้องกันแรงกระแทก การลุกลามความร้อน และการเข้าถึงเพื่อซ่อม
- พฤติกรรมเมื่อแบตเตอรี่ต่ำ การหยุดอย่างปลอดภัย และการปิดระบบแบบควบคุม
- เวลาชาร์จ รวมถึงแหล่งที่มาและความเข้ากันได้ของเครื่องชาร์จ

ความจุพลังงาน (Wh) เพียงอย่างเดียวไม่เพียงพอ เพราะกำลังสูงสุด กระแส ขีดจำกัดความร้อน และพลังงานสำรองอาจเป็นข้อจำกัดหลัก

## 7. การคำนวณวนซ้ำระหว่างน้ำหนัก กำลัง และความร้อน

น้ำหนัก แรงบิด กำลัง และแบตเตอรี่สัมพันธ์กัน แบตเตอรี่ที่ใหญ่ขึ้นเพิ่มน้ำหนักที่ต้องรองรับ น้ำหนักที่เพิ่มขึ้นเพิ่มแรงที่ข้อต่อและพลังงานที่ใช้ ส่วนแอคชูเอเตอร์และระบบส่งกำลังที่ใหญ่ขึ้นเพิ่มน้ำหนักและภาระความร้อน

ลำดับการคำนวณวนซ้ำ:
1. กำหนดภารกิจและสมมติฐานรูปทรง
2. ประเมินน้ำหนักรายระบบและจุดศูนย์ถ่วง
3. คำนวณกรณีรับแรง แรงบิด และความเร็วข้อต่อ
4. คัดกรองชุดขับ/ระบบส่งกำลังจาก datasheet ที่ตรวจสอบได้
5. ประเมิน duty cycle ทางไฟฟ้าและการระบายความร้อน
6. คำนวณแบตเตอรี่และอิเล็กทรอนิกส์กำลัง
7. ปรับน้ำหนักรวมและจุดศูนย์ถ่วง
8. คำนวณแรงใหม่และทำซ้ำจนระยะเผื่อมีแนวโน้มคงที่
9. บันทึกความไวของผลลัพธ์และความเสี่ยงที่ยังไม่คลี่คลาย ห้ามปกปิดรอบคำนวณที่ไม่ผ่าน

สเปรดชีตหรือสคริปต์ที่ใช้ต้องแสดงสมมติฐาน หน่วย สมการ แหล่งข้อมูล ประวัติรุ่น และสถานะการทดสอบอย่างชัดเจน ห้ามใช้ตัวเลขสรุปที่ตรวจสอบที่มาไม่ได้

## 8. ประตูหลักฐานและการออกแบบ

| ขั้น | หลักฐานที่ต้องผ่าน |
|---|---|
| M1 — ข้อมูลภารกิจ | ภารกิจตัวแทนที่อนุมัติ สภาพแวดล้อม ขอบเขตใช้งาน และเกณฑ์ยอมรับที่วัดได้ |
| M2 — บัญชีน้ำหนัก | ค่าประมาณรายระบบที่ตรวจสอบย้อนกลับได้ นิยาม payload ความไม่แน่นอน และยอดรวมเทียบ 18–22 กก. |
| M3 — จลนศาสตร์และกรณีรับแรง | รูปทรงหุ่นยนต์ สมมติฐาน gait กรณีสัมผัสพื้น และผล inverse dynamics ที่ทำซ้ำได้ |
| M4 — รายชื่อชุดขับที่พิจารณา | Datasheet รุ่นจริง ขีดจำกัดแรงบิด-ความเร็ว/ความร้อนที่ตรวจสอบได้ แหล่งที่มา และความเข้ากันได้ |
| M5 — ระบบไฟฟ้าและแบตเตอรี่ | โปรไฟล์โหลดตามเวลา การวิเคราะห์กระแสสูงสุด การป้องกันแบตเตอรี่/BMS และเหตุผลของพลังงานสำรอง |
| M6 — การจำลองและแท่นทดสอบ | ผลจำลองที่ทำซ้ำได้ พร้อมหลักฐานการวัดชุดขับ ไดรเวอร์ ระบบไฟฟ้า และความร้อน |
| M7 — ทดสอบหุ่นยนต์แบบควบคุม | การประเมินความเสี่ยงที่อนุมัติ และผลวัดจากการทดสอบแบบเพิ่มระดับในหลาย configuration/พื้นผิว |

การจัดทำเอกสารอย่างเดียวไม่ถือว่าผ่าน gate ต้องมีหลักฐานที่ตรวจทานเทียบเกณฑ์ยอมรับ การจำลองไม่ใช่การยืนยันผลทางกายภาพ

## 9. ข้อจำกัดด้านความน่าเชื่อถือและความปลอดภัยของ PUI89

- ใช้นโยบาย PUI89 ที่ไม่พึ่งพาส่วนประกอบ แหล่งผลิต ผู้ขาย เจ้าของ/ผู้ควบคุม เฟิร์มแวร์ ซอฟต์แวร์ วัสดุ และการเข้าถึงข้อมูลที่มีต้นกำเนิดจากจีนหรืออยู่ภายใต้การควบคุมจากจีน
- แหล่งกำเนิดหรือ provenance ที่ไม่ทราบหรือพิสูจน์ไม่ได้ถือเป็นเงื่อนไขกีดกัน ไม่ใช่การถือว่าผ่าน
- ให้ความสำคัญกับอินเทอร์เฟซแบบโมดูลาร์ ซ่อมได้ เปลี่ยนทดแทนได้ และหลีกเลี่ยงการผูกขาดผู้ขายรายเดียว
- เอกสารนี้ไม่อนุญาตให้จัดซื้อ ผลิต ติดตั้ง หรือนำไปทดสอบภาคสนาม
- ห้ามอ้างความสามารถด้าน payload ความเร็ว ระยะเวลาทำงาน การป้องกันการล้ม ภูมิประเทศ หรือสมรรถนะชุดขับ หากไม่มีหลักฐานวัดจริง
- ขีดจำกัดความปลอดภัยและการหยุดฉุกเฉินต้องไม่ขึ้นกับผลลัพธ์ของ AI เพียงอย่างเดียว

## 10. บันทึกการตัดสินใจปัจจุบัน

เป้าหมายน้ำหนักรวม 18–22 กก. ยังคงเป็นเป้าหมายสำหรับการศึกษาทางวิศวกรรมเบื้องต้น ภารกิจ ขนาด จำนวนข้อต่อ gait payload สถาปัตยกรรมชุดขับ เคมี/ความจุแบตเตอรี่ ระยะเวลาทำงาน ต้นทุน และรายชื่อผู้ขายยัง **ไม่กำหนด** การตัดสินใจทางเทคนิคถัดไปคืออนุมัติภารกิจตรวจสอบตัวแทนหนึ่งรูปแบบภายใต้การกำกับของมนุษย์ พร้อมขอบเขตการใช้งานที่วัดผลได้ จากนั้นจึงกรอกการคำนวณแรงบิดและแบตเตอรี่เป็นตัวเลข
