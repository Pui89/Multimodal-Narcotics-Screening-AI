# PUI89 Sentinel — กรอบวิศวกรรมหุ่นยนต์น้ำหนักเบาถึงสมดุล v0.1

**สถานะ:** อนุมัติทิศทางวิศวกรรมเบื้องต้นแล้ว; อยู่ในขั้นกำหนดข้อกำหนดและวิเคราะห์  
**วันที่:** 2026-11-21  
**ผลิตภัณฑ์:** หุ่นยนต์สี่ขาสำหรับสำรวจและตรวจสอบภายใต้การกำกับของมนุษย์  
**การจัดซื้อ / ผลิต / นำไปใช้งาน:** เอกสารนี้ไม่ใช่การอนุมัติ

## 1. ทิศทางการออกแบบที่อนุมัติ

พัฒนา Sentinel เป็น **หุ่นยนต์สี่ขาสำหรับสำรวจและตรวจสอบที่มีน้ำหนักเบาถึงสมดุล และมุ่งรองรับภูมิประเทศหลากหลาย** ให้ความสำคัญกับการเดินที่แข็งแรง คล่องตัว ควบคุมได้ มีเสถียรภาพ ลดความเสี่ยงจากการล้ม มีระยะเวลาทำงานที่เหมาะสม บำรุงรักษาได้ และควบคุมต้นทุน ไม่ลดน้ำหนักจนกระทบความแข็งแรง เสถียรภาพ การจัดการความร้อน หรืออายุการใช้งาน

คำว่า All-Terrain เป็นทิศทางการพัฒนาเท่านั้น ขอบเขตการใช้งานจริงต้องระบุชนิดพื้นผิว ความลาดชัน สิ่งกีดขวาง สภาพอากาศ และเงื่อนไขห้ามใช้งานที่ผ่านการทดสอบ

## 2. เป้าหมายน้ำหนักเบื้องต้น

| รายการ | กรอบเบื้องต้น | สถานะ |
|---|---:|---|
| น้ำหนักเป้าหมายของหุ่นยนต์ทั้งระบบ | **18–22 กก.** | อนุมัติให้ใช้ศึกษาทางวิศวกรรม; ยังไม่ใช่น้ำหนักที่วัดหรือยืนยันแล้ว |
| ความสามารถในการบรรทุก | ยังไม่กำหนด | ต้องคำนวณจากภารกิจ เสถียรภาพ และแรงของชุดขับ |
| น้ำหนักอุปกรณ์ภารกิจเพิ่มเติม | แยกจากน้ำหนักเป้าหมาย เว้นแต่จะกำหนดในบัญชีน้ำหนักฉบับต่อไป | ต้องยืนยันนิยามในขั้นออกแบบรายละเอียด |
| แบตเตอรี่ เซนเซอร์พื้นฐาน คอมพิวเตอร์บนตัวหุ่นยนต์ และฝาครอบป้องกัน | ให้นับรวมในน้ำหนักหุ่นยนต์ทั้งระบบ | หลักการจัดทำบัญชีน้ำหนัก |
| ขนาด ความสูง ฐานล้อ/ฐานยืน และระยะเอื้อมของขา | ยังไม่กำหนด | ห้ามตรึงก่อนเลือกภารกิจและศึกษา CAD/การจัดวาง |

ช่วง 18–22 กก. เป็นเป้าหมายของหุ่นยนต์พื้นฐานทั้งระบบ โดยรวมแบตเตอรี่ เซนเซอร์พื้นฐาน คอมพิวเตอร์ และฝาครอบแล้ว อุปกรณ์ภารกิจเพิ่มเติมต้องแสดงแยกในบัญชีน้ำหนัก น้ำหนักสุดท้ายอาจเปลี่ยนได้หากการคำนวณพบว่าไม่สามารถผ่านข้อกำหนดด้านความปลอดภัย ความทนทาน เสถียรภาพ หรือระยะเวลาทำงานได้ภายในช่วงนี้ ไม่มีการอ้างว่ามีต้นแบบที่มีน้ำหนักดังกล่าวแล้ว

## 3. ลำดับความสำคัญในการออกแบบ

1. การเดินสี่ขาที่ควบคุมได้ มีเสถียรภาพ และจัดการจุดศูนย์ถ่วงได้
2. ความคล่องตัวและความเร็วที่เหมาะกับพื้นผิว น้ำหนักบรรทุก และความเสี่ยง
3. ลดความเสี่ยงจากการล้ม การหยุดอย่างปลอดภัย และแนวทางกู้คืนภายใต้การกำกับ
4. ความแข็งแรงของโครงสร้างและอายุความล้าภายใต้งบประมาณน้ำหนักที่เหมาะสม
5. ชุดขับและระบบส่งกำลังที่คำนวณจากแรงบิดและภาระของข้อต่อ
6. แบตเตอรี่และระบบพลังงานที่คำนวณจากรอบการทำงานจริง ภาระสูงสุด และพลังงานสำรองเพื่อความปลอดภัย
7. การจัดการความร้อนของแอคชูเอเตอร์ ไดรเวอร์ แบตเตอรี่ และคอมพิวเตอร์
8. โมดูลขา เท้า แอคชูเอเตอร์ แบตเตอรี่ เซนเซอร์ และขั้วต่อที่เปลี่ยนซ่อมได้
9. ซ่อมบำรุงได้ ใช้อินเทอร์เฟซแบบโมดูลาร์ และหลีกเลี่ยงชิ้นส่วนสั่งทำที่ไม่จำเป็น
10. ตรวจสอบแหล่งที่มาของส่วนประกอบและความน่าเชื่อถือของห่วงโซ่อุปทานตามนโยบาย PUI89

## 4. งานวิศวกรรมที่ต้องทำก่อนกำหนดขนาดหรือเลือกฮาร์ดแวร์ขั้นสุดท้าย

- เลือกภารกิจตรวจสอบหนึ่งรูปแบบที่มีมนุษย์กำกับ พร้อมกำหนดพื้นที่ ระยะเวลา ความเร็ว สิ่งกีดขวาง และความลาดชัน
- จัดทำบัญชีน้ำหนักรายระบบ: โครงสร้าง ขาทั้งสี่ แอคชูเอเตอร์/ระบบส่งกำลัง เท้า แบตเตอรี่/BMS คอมพิวเตอร์ เซนเซอร์ สายไฟ ฝาครอบ และอุปกรณ์ภารกิจ
- คำนวณแรงบิด ความเร็ว ภาระต่อเนื่องและสูงสุด แรงกระแทก และการระบายความร้อนของข้อต่อ
- วิเคราะห์ความแข็งแรง ความล้า สกรู แบริ่งข้อต่อ การสัมผัสพื้น และการเข้าถึงเพื่อซ่อมบำรุง
- ประเมินจุดศูนย์ถ่วงและระยะเผื่อเสถียรภาพ ทั้งกรณีไม่บรรทุกและบรรทุกอุปกรณ์ตัวแทน
- คำนวณพลังงานและกำลังแบตเตอรี่ ขีดจำกัดความร้อน และพลังงานสำรองสำหรับหยุด/กลับอย่างปลอดภัย
- กำหนดขนาดจากความกว้างทางผ่าน รูปทรงสิ่งกีดขวาง ท่ายืน ระยะเอื้อมของขา เสถียรภาพ การขนย้าย และการซ่อมบำรุง
- เปรียบเทียบทางเลือกด้านต้นทุนด้วย BOM ที่ตรวจสอบย้อนกลับได้และใบเสนอราคาจากผู้ขายเป็นลายลักษณ์อักษร เอกสารนี้ยังไม่ได้กำหนดงบประมาณ

## 5. ประตูการตรวจสอบและยืนยันผล

| ขั้น | หลักฐานที่ต้องมี |
|---|---|
| G1 — ภารกิจและขอบเขตการทำงาน | กรณีใช้งาน สถานที่ สมมติฐาน อันตราย พื้นผิว ความลาดชัน สิ่งกีดขวาง รอบการทำงาน และเกณฑ์ยอมรับที่วัดได้ |
| G2 — น้ำหนักและการจัดวาง | บัญชีน้ำหนักรายระบบ แบบ CAD/การจัดวาง การประเมินจุดศูนย์ถ่วง และการตรวจสอบการเข้าถึงเพื่อซ่อม |
| G3 — โครงสร้างและชุดขับ | กรณีแรงคำนวณ แรงบิด/ความเร็ว/รอบการทำงาน การวิเคราะห์โครงสร้างและความล้า รวมถึงข้อต่อและเท้า |
| G4 — พลังงานและความร้อน | งบพลังงาน/กำลังแบตเตอรี่ ระบบป้องกัน BMS การวิเคราะห์ความร้อน และพลังงานสำรอง |
| G5 — Simulation และ Bench Test | การจำลองการเดิน/เสถียรภาพ และหลักฐานทดสอบชุดขับ พลังงาน ความร้อน เซนเซอร์ และหยุดฉุกเฉิน |
| G6 — การทดสอบหุ่นยนต์จริงแบบควบคุม | ทดสอบในอาคารและพื้นผิวที่เลือกทีละขั้น วัดเสถียรภาพ ความเร็ว น้ำหนักบรรทุก ระยะเวลาทำงาน การกู้คืน และความล้มเหลว |
| G7 — ทดลองภาคสนามภายใต้การกำกับ | การทบทวนความปลอดภัยโดยอิสระ และการอนุมัติจากสถานที่/ผู้ปฏิบัติงาน พร้อมหลักฐานตามขอบเขตที่ประกาศ |

การผ่านขั้นหนึ่งไม่ได้หมายถึงผ่านขั้นถัดไป ผลจำลองไม่ใช่การยืนยันทางกายภาพ และการทดสอบพื้นผิวหรือน้ำหนักบรรทุกหนึ่งรูปแบบไม่สามารถยืนยันความสามารถ All-Terrain ได้โดยทั่วไป

## 6. ขอบเขตที่ต้องรักษา

- ห้ามอ้างความเร็ว น้ำหนักบรรทุก ระยะเวลาทำงาน ความลาดชัน ความสูงสิ่งกีดขวาง การต้านการล้ม ระดับการป้องกันฝุ่น/น้ำ หรืออายุใช้งานที่ยังไม่มีหลักฐานทดสอบ
- ห้ามใช้เพื่อบังคับใช้กฎหมาย ไล่ติดตาม หรือเข้าพื้นที่อันตรายโดยไม่มีผู้กำกับ
- เมื่อสูญเสียการระบุตำแหน่ง เท้าไม่ปลอดภัย เซนเซอร์สำคัญขัดแย้ง การสื่อสารล้มเหลว หรือพบอันตรายที่ไม่ทราบ ต้องเข้าสู่การตอบสนองที่ปลอดภัยตามภารกิจและแจ้งผู้ควบคุม
- RGB, Depth และ LiDAR ไม่สามารถรับรองความปลอดภัยของบรรยากาศหรือทดแทนเครื่องตรวจวัดก๊าซที่สอบเทียบแล้วและขั้นตอนความปลอดภัยของสถานที่
- เอกสารนี้ไม่อนุมัติการซื้อชิ้นส่วน การผลิต หรือการทดลองภาคสนาม
- ก่อนอนุมัติต้องตรวจสอบผู้ผลิต รุ่น/หมายเลขชิ้นส่วน ประเทศที่ผลิต หลักฐานแหล่งกำเนิด ผู้ขายและผู้มีอำนาจควบคุม แหล่งที่มาของเฟิร์มแวร์/ซอฟต์แวร์ และความสามารถในการเปลี่ยนทดแทน หากตรวจสอบแหล่งที่มาไม่ได้ ให้ถือเป็นสิ่งกีดขวางตามนโยบาย PUI89

## 7. บันทึกการตัดสินใจ

ผู้ใช้อนุมัติทิศทางหุ่นยนต์ตรวจสอบและสำรวจแบบน้ำหนักเบาถึงสมดุล พร้อม **เป้าหมายน้ำหนักหุ่นยนต์ทั้งระบบเบื้องต้น 18–22 กก.** เมื่อวันที่ 2026-11-21 ใช้เป็นกรอบศึกษาทางวิศวกรรมเท่านั้น ขนาด ความสามารถในการบรรทุก สถาปัตยกรรมชุดขับ แบตเตอรี่ ระยะเวลาทำงาน ต้นทุน และขอบเขตการใช้งานยังเป็นประเด็นที่ต้องตัดสินใจต่อ
